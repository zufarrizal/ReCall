# ReCall v0.1.2

Rilis ini memperbaiki alarm yang tidak menghasilkan suara pada sebagian konfigurasi Windows.

## Perbaikan

- Menambahkan pola suara native Windows yang diputar langsung oleh aplikasi.
- Mengganti suara toast menjadi kategori pengingat dengan durasi panjang.
- Menambahkan tombol **Uji suara alarm** agar perangkat output dapat diperiksa langsung.
- Tetap menampilkan toast dan dialog alarm meskipun pemutaran suara gagal.

## Pengembangan

- Menambahkan knowledge graph Graphify untuk navigasi dan pemeliharaan codebase.

Unduh `ReCall.exe` dari bagian Assets. Aplikasi bersifat portable dan tidak memerlukan instalasi.
