# ReCall v0.1.3

Rilis ini memperbaiki ketidakselarasan batas kolom pada tampilan kalender mingguan ketika digeser horizontal.

## Perbaikan

- Header hari, kolom waktu, dan badan kalender kini menggunakan satu definisi ukuran grid.
- Kolom jam tidak lagi menutupi sebagian badan hari saat posisi horizontal berada di ujung kanan.
- Header dan slot waktu bergerak bersama sehingga batas setiap hari tetap sejajar.

Unduh `ReCall.exe` dari bagian Assets. Aplikasi bersifat portable dan tidak memerlukan instalasi.
