# ReCall v0.1.4

Rilis ini memperbaiki area gelap pada sisi kanan kalender Minggu ketika aplikasi digunakan dalam jendela yang tidak dimaksimalkan.

## Perbaikan

- Lebar badan kalender Minggu sekarang selalu mencakup seluruh tujuh kolom hari.
- Kolom Jumat dan Sabtu tidak lagi memperlihatkan warna latar aplikasi saat kalender digeser horizontal.
- Header hari, latar slot waktu, dan garis grid tetap konsisten hingga kolom terakhir.

Unduh `ReCall.exe` dari bagian Assets. Aplikasi bersifat portable dan tidak memerlukan instalasi.
