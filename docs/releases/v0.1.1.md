# ReCall v0.1.1

Rilis Windows pertama ReCall, aplikasi agenda desktop berbasis Go, Wails, dan SQLite.

## Fitur

- Kalender agenda dengan tampilan 1 hari, 3 hari, dan 1 minggu.
- Penyimpanan SQLite lokal tanpa memerlukan server.
- Alarm dan notifikasi Windows otomatis.
- Berjalan di background melalui system tray.
- Form tambah/ubah agenda, konfirmasi hapus, dan notifikasi status.

## Perbaikan

- Menu **Keluar** pada system tray kini menghentikan aplikasi sepenuhnya.
- Kalender dapat digulir untuk melihat seluruh waktu dari pukul 00:00 sampai 23:00.

## Unduhan

Unduh `ReCall-Windows-x64.exe` dari bagian Assets. Aplikasi bersifat portable dan tidak memerlukan instalasi.

> Windows mungkin menampilkan peringatan SmartScreen karena executable belum ditandatangani dengan sertifikat code-signing.
