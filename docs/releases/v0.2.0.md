# ReCall v0.2.0

Rilis ini memperluas kemampuan kalender untuk menangani beberapa agenda pada waktu yang sama dan mempersonalisasi kategori warna.

## Fitur baru

- Agenda yang waktunya bertumpuk pada hari yang sama kini ditampilkan berdampingan sehingga semuanya tetap terlihat dan dapat dipilih.
- Pilihan warna agenda bertambah menjadi sepuluh kategori.
- Nama setiap kategori warna dapat diubah melalui modal **Atur nama**.
- Nama kategori disimpan permanen di SQLite dan tetap tersedia setelah aplikasi dijalankan ulang.

## Perubahan

- Formulir agenda dan legenda kalender membaca nama kategori langsung dari database.
- Token warna divalidasi sebelum disimpan untuk menjaga konsistensi tampilan dan mencegah nilai CSS yang tidak aman.
- Migrasi database menambahkan kategori baru tanpa menimpa nama yang sudah dipersonalisasi.
- Metadata Windows pada executable sekarang menampilkan versi produk `0.2.0`.

Unduh `ReCall.exe` dari bagian Assets. Aplikasi bersifat portable dan tidak memerlukan instalasi.
